# Project Goal

## 总目标

构建个人数据基础设施中的本地摄像头系统，使 xiao vv 摄像头尽可能脱离厂商云端，通过本地服务器完成视频流接入、存储、识别、通知与自动跟踪。

## 阶段目标

| 阶段 | 目标 |
|---|---|
| P0 | 建立实验环境与记录体系 |
| P1 | 分析摄像头网络行为 |
| P2 | 尝试本地视频流接管 |
| P3 | 串口只读分析 |
| P4 | 固件备份与恢复验证 |
| P5 | 最小固件修改 |
| P6 | 服务器侧功能接管 |
| P7 | 长期稳定运行 |

## 当前原则

- 优先尝试网络层接管。
- 如果能直接获得本地视频流，暂不刷机。
- 串口阶段先只读，不急于输入命令。
- 固件修改前必须完成 SPI Flash 完整备份与恢复验证。
